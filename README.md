# Inkframe

A drawing and animation app for iPad (works in any modern browser too). Draw with Apple Pencil, animate frame by frame or with tweens, and export GIFs, MP4 videos, PNG sequences and SVG.

**Open the app:** https://nojux.github.io/Apple_animatingapp/

## Install on iPad
1. Open the link above in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open Inkframe from its new icon. It runs full screen and works offline.

## Features
- Vector brush with Apple Pencil pressure, even-width pen, partial or whole-stroke eraser
- Line, rectangle and ellipse tools, fill tool, select / move / resize / rotate / flip
- Timeline with layers (show/hide, lock, reorder, rename), keyframes, blank keyframes, held frames
- Onion skin, playback at any frame rate, looping
- Shape and motion tweens with easing
- Undo/redo (two-finger tap / three-finger tap), pinch to zoom, palm rejection once the Pencil is used
- Save like a desktop app: the first Save (⌘S) names the animation, then every change autosaves to it. Unsaved work is kept on the device until you save or discard it. Several projects, project file backup (.inkframe)
- Export: GIF, MP4, PNG sequence (.zip), PNG frame, SVG frame, animated SVG

No build step: it is plain HTML, CSS and JavaScript. Serve the folder with any static web server.
